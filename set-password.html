Set the submission password

This page is a local tool — it is not linked from the site and sends nothing anywhere. It turns a password into the two values index.html stores, so the password itself never has to be written down in the code.

Open index.html, find SUBMIT: PASSWORD GATE, and replace those two lines with these:


    

      Anyone already unlocked in an open tab stays unlocked until they close the
      browser. Everyone else needs the new password immediately.
    

  


  

    
Reminder about what this protects.

    
    
      
  1. The check runs in the visitor's browser, so it keeps out everyone browsing normally — not someone determined who reads the page source.

  2. That is the right level for a submissions form. Do not put anything genuinely confidential behind it.
